# Start here

This section is a tutorial. It has one path, in order, with no choices along
the way. Follow it once, and you have a working rollout.

If you already know Factoriax and want to solve a specific task, go to
{doc}`../training/index` instead. If you want the reasoning behind a design
choice, go to {doc}`../understanding/index`.

- **{doc}`getting_started`**: install Factoriax, build an environment, read
  the observation and action spaces, and run a random rollout.
